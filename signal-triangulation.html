Triangulation Confidence Score (TCS) Methodology

TCS = (0.30 × FAERS_Score) + (0.30 × PubMed_Score) + (0.25 × CT_Score) + (0.15 × Label_Novelty)

Step 1 – Primary Signal Detection (FAERS): The engine queries the FDA Adverse Event Reporting System (FAERS) via the openFDA API, computes Proportional Reporting Ratios (PRR) for all drug–event pairs, and flags primary signals where PRR > 2.0 and case count ≥ 3 (configurable thresholds).
Step 2 – Literature Evidence (PubMed): For each primary signal, PubMed is queried through the NCBI E-utilities API to count publications mentioning the drug and the adverse event. A PubMed_Score between 0.0 and 1.0 is assigned based on the publication count and approximate evidence level (case reports, series, observational studies, etc.).
Step 3 – Clinical Trial Evidence (ClinicalTrials.gov): Clinical experience is assessed by querying ClinicalTrials.gov API v2 for completed studies of the drug (or a PubMed-based proxy when CORS prevents direct access). A CT_Score between 0.0 and 1.0 is derived from the number of completed trials and, in enhanced embodiments, from adverse event frequencies in treatment versus control arms.
Step 4 – Label Status and Novelty (DailyMed): Labeling is checked using the DailyMed API and heuristic mapping for common labeled events. A Labeling_Status_Score reflects which section of the label (if any) mentions the adverse event. Label_Novelty is computed as the inverse of this score, so unlabeled or weakly labeled events receive higher novelty values.
Step 5 – TCS Calculation and Classification: FAERS_Score is obtained by normalizing PRR (PRR/10, capped at 1.0). The Triangulation Confidence Score combines FAERS_Score, PubMed_Score, CT_Score, and Label_Novelty using the weighted formula above. Each signal is then classified:
Validated TCS > 0.65 | Probable TCS 0.40–0.65 | Possible TCS 0.20–0.40 | Refuted TCS < 0.20
Step 6 – Structured Triangulation Output: For every signal shown in the table, the engine exposes the FAERS statistics, source-specific scores, TCS, and classification in a structured row that can be exported or used as the basis for formal triangulation reports.
Step 7 – Continuous Monitoring and Trend Tracking: The engine is designed to be re-run periodically for the same drug as new FAERS reports, publications, trial data, or labeling updates become available. By comparing current TCS values to prior runs, users can identify increasing trends and escalate borderline signals as evidence accumulates.
